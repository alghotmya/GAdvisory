# GAdvisory (GoO Strategic Advisor)

React + TypeScript + Vite app for this project. Source lives under `src/` (see `src/App.tsx`).

## Run locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Repository

Remote: `https://github.com/alghotmya/GAdvisory` — default branch: `main`.
